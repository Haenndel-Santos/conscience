# Briefs históricos

Prompts de trabalho entregues a agentes ao longo do desenvolvimento do projeto,
movidos da raiz do repositório em 2026-08-12.

**Estatuto: registro de proveniência, não instrução ativa.** Cada arquivo descreve o
que foi pedido a um agente numa data específica, com o estado do projeto naquele
momento. Não devem ser lidos como especificação corrente — vários descrevem tarefas já
concluídas, e alguns contêm suposições que a revisão posterior desfez. Para o estado
atual, ver `README.md` e `CHECKLIST_pendencias.md`, na raiz.

São mantidos porque documentam *como* cada peça do projeto foi encomendada — incluindo
as regras de governança sob as quais os agentes trabalharam (por exemplo, a exigência
de que scripts fossem escritos por agente mas executados localmente pelo autor, contra
dado real). Essa cadeia importa para avaliar o que foi computado e o que foi apenas
proposto.
