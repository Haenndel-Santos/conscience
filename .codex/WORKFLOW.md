# Fluxo Ideal de Trabalho

## 1. Expandir capítulos

Use `chapter-expansion-workflow` para transformar notas em prosa contínua. Cada capítulo deve ter abertura conceitual, desenvolvimento progressivo, exemplos concretos, retomada do núcleo integrativo e transição para o próximo capítulo.

## 2. Revisar coerência teórica

Use `theory-core-guardian` após cada expansão relevante. Verifique se o texto preserva corpo constitutivo, regime dinâmico, integração diferenciada, determinismo estratificado, common knowledge e o estatuto de `\mathcal{C}(t)`.

## 3. Conferir hard problem

Use `hard-problem-and-philosophy-checker` nas passagens sobre experiência, subjetividade, lacuna explicativa, emergência e limites da teoria. A meta é afirmar avanços sem prometer solução total.

## 4. Conferir referências

Use `citation-and-reference-guardian` antes de consolidar capítulos. Classifique cada referência como texto fornecido, literatura verificada, influência conceitual ampla ou item a verificar.

## 5. Testar formalismo

Use `formalism-and-model-guardian` para revisar símbolos, variáveis, índices e modelos. Confirme que `\Psi_{\text{eff}}`, `Q(t)`, `\mathcal{C}(t)`, `S(t)`, `E(t)` e `B(t)` têm status claro e não prometem mais do que o texto sustenta.

## 6. Integrar casos-limite

Use `boundary-cases-lab` para sonho, psicodélicos, trauma, consciência animal, desenvolvimento infantil, linguagem e IA. Cada caso deve testar a teoria, não aparecer como anexo solto.

## 7. Desenvolver o capítulo sobre IA

Use `ai-consciousness-boundary` para distinguir automação inteligente, modelagem, corpo constitutivo, interocepção, alostase, auto-manutenção e experiência. A posição deve ser crítica sem caricatura.

## 8. Ajustar arquitetura do livro

Use `manuscript-architecture-editor` para revisar sumário, ordem, extensão, transições, prefácio, conclusão e implicações. O livro deve ser legível como obra contínua, não apenas correto como coleção de argumentos.

## 9. Preparar preprint ou livro

Antes de versão pública, execute uma revisão em camadas: núcleo, filosofia, referências, formalismo, casos-limite, arquitetura e estilo. Qualquer lacuna bibliográfica ou formal deve ser marcada antes de circulação.
