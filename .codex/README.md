# Ecossistema Codex Skills do Projeto

Este diretório contém skills locais para o projeto **Consciência como Regime Integrado: Corpo, Gradiente, Determinismo Estratificado e Coordenação Intersubjetiva**.

O objetivo é fazer o Codex atuar como copiloto editorial, teórico e metodológico sem perder a coerência do manuscrito. As skills foram criadas em `.codex/skills/` como prioridade. Não foram espelhadas em `.agents/skills/` para evitar duplicação e divergência entre cópias; se algum fluxo futuro exigir esse espelhamento, ele deve ser feito de modo mecânico e verificado.

## Princípio central

A consciência deve ser tratada como um regime dinâmico integrado: uma solução evolutiva para coordenar sistemas sensoriais, corporais, valorativos, agentes e sociais em um campo funcional comum. O corpo é constitutivo, a agência é integrada sob determinismo estratificado, e a dimensão social superior envolve common knowledge, publicidade e ratificação intersubjetiva.

## Skills

- `theory-core-guardian`: protege o núcleo inegociável da teoria e detecta desvios conceituais.
- `manuscript-architecture-editor`: organiza o manuscrito como livro, cuidando de capítulos, transições, ritmo e conclusão.
- `citation-and-reference-guardian`: garante honestidade bibliográfica, evita referências inventadas e distingue fonte textual, literatura verificada e influência geral.
- `hard-problem-and-philosophy-checker`: mantém o tratamento do hard problem filosoficamente honesto.
- `formalism-and-model-guardian`: verifica a consistência entre prosa teórica e formalismo, incluindo `\Psi_{\text{eff}}`, `Q(t)`, `\mathcal{C}(t)`, `S(t)`, `E(t)` e `B(t)`.
- `chapter-expansion-workflow`: orienta expansões longas de capítulos em prosa acadêmico-ensaística.
- `boundary-cases-lab`: usa sonhos, psicodélicos, trauma, animais, desenvolvimento, linguagem e IA como testes da teoria.
- `ai-consciousness-boundary`: delimita o debate entre consciência biológica, automação inteligente e IA.

## Como elas se complementam

Use `chapter-expansion-workflow` para produzir texto longo, `theory-core-guardian` para verificar coerência, `manuscript-architecture-editor` para ajustar a posição do capítulo no livro, `citation-and-reference-guardian` para limpar o aparato bibliográfico, `formalism-and-model-guardian` para controlar variáveis e índices, `hard-problem-and-philosophy-checker` para evitar promessas filosóficas exageradas, `boundary-cases-lab` para tensionar a teoria e `ai-consciousness-boundary` para o debate específico sobre IA.

## Como usar o Codex sem perder coerência

Peça uma tarefa por vez quando o trecho for longo: expandir, revisar núcleo, revisar referências, checar formalismo ou integrar casos-limite. Para capítulos centrais, use uma sequência conservadora: expansão inicial, revisão do núcleo, revisão filosófica, revisão bibliográfica, revisão formal e revisão arquitetural.

O Codex deve sempre distinguir hipótese, interpretação, formalização e evidência empírica. Também deve declarar quando uma obra não foi lida diretamente ou quando uma referência precisa ser verificada antes de entrar em versão final.
