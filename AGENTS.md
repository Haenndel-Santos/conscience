# Agent Instructions

This repository contains theory text, conceptual simulations, data tables, figures, and Codex skill instructions for the Conscience project.

## Working Rules

- Preserve the theoretical scope of the project.
- Do not delete manuscripts, CSV files, PNG figures, simulations, or `.codex` materials without explicit authorization.
- Record important structural or methodological changes in documentation.
- Keep README and project guidance current when changing organization or workflows.
- Before changing Python scripts, inspect imports and expected dependencies.
- Before versioning large outputs, review whether each file is source data, a reproducible result, or a temporary artifact.
- Do not install dependencies, connect remotes, push, or run heavy simulations unless explicitly requested.

## Project-Specific Guidance

Detailed Codex workflow and theory guardrails live under `.codex/`. Use those files as the source of project-specific agent behavior.
