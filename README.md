# Conscience

Conscience is an early-stage project for integrated consciousness theory, conceptual simulations, and supporting documentation.

## Structure

- `.codex/` contains project guidance, workflow notes, and local agent skills.
- `dados atuais/` contains current simulation scripts, CSV tables, and generated figures used as part of the project baseline.
- `Versao atual.txt` contains the current manuscript or theory draft.

## Status

This project is in an initial research and organization stage. Treat theory text, simulation code, CSV files, figures, and agent instructions as project material unless they are explicitly reviewed as temporary outputs.

## Python Environment

The simulation scripts appear to use Python with packages such as NumPy, pandas, Matplotlib, and scikit-learn. Create and activate a local virtual environment before running or changing scripts, then install dependencies according to a reviewed requirements file when one exists.

No dependencies are installed automatically by this repository.
